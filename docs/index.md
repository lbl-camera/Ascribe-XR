# Ascribe XR

ASCRIBE-XR is an immersive VR scientific-visualization application for Meta Quest headsets. This app aims to
fill in for the lack of free, open-source, comprehensive visualization software by allowing users to visualize volumetric, CT, and mesh data within a VR space. It allows for real world experiments to be fully interacted with as 3D objects. Currently built in Godot 4.6, ASCRIBE-XR currently allows for multi-user syncronization and a remote servery to offload heavy computations to remote compute resources. Furthermore, AI assisted data processing has been integrated within Ascribe-XR, allowing for users to prompt for different types of visualizations. These tools will give researchers and scientists a means for better data comprehension.

If you're interesting more about Ascribe-XR consider getting started with the developer or user guides!
